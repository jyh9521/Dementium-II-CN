## 固定执行边界

- 未获用户新的明确指令，不启动游戏，不进行自动界面操作。
- Steam 安装目录保持只读；不安装实验补丁到真实目录。
- 所有修改产物在 build/，发行实验包在 dist/。
- 每次回报均区分离线验证与真实游戏验收。
- 不发布 GitHub Release；不上传游戏原件、完整修改包或内部工程规范。
