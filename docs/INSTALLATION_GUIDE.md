# 安装与恢复

当前全文测试包为 dist/Dementium-II-zh-CN-preview.zip，说明见 [玩家说明](PLAYER_README.md)。
先退出游戏，再运行安装器。安装器验证原包与EXE身份，分别保留 original.zar、original.exe，
只修改两个目标文件，不操作存档或Steam设置；卸载恢复两个原件。
开发输出位于 build/full-zh-CN，可由用户手动运行其中Dementium II.exe；工具不自动启动。
ROLLBACK_FULL.sh仅向另一个目录导出恢复文件，不覆盖待验收的修改副本。
历史最小实验与早期单资源补丁不代表当前全文版本。
