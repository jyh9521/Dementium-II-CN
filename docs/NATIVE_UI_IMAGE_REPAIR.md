# 原生操作图像修复（2026-10-21）

## 已验证的根因

- 先前 12 张操作图使用整张 `art_delta`，该分支绕过原生区域文字重建，带入了不透明键盘面板、重画的方向图形和错误的 Jump 字形。
- 原键盘面板的背景为 RGBA `(0,0,0,67)`，不是 alpha255 的纯黑；原始边框也必须直接保留。
- 图例按保留区居中会改变按钮与文字之间的距离；Back 的 23 像素字形还会逼近按钮。
- Y Axis 原图确有末尾冒号；只清除到 x187 会把原冒号留成第二个冒号。

## 可复现修复

`locales/zh-CN/image-text.json` 的 12 张操作图取消整图差分，从哈希锁定的原始 PNG 开始，仅清除经过审阅的英文文字矩形，并用 Fusion12 原生像素字形重绘。键帽、手柄、连线、方向箭头、边框和文字区外的透明度直接使用原像素。

- PC TYPE1/2/3：十字键说明的可见字形围绕 x84 对齐，四个方向箭头设置独立原像素保护区；A 始终为“跳跃”。
- NX TYPE1/2/3：同样围绕原图 x88 对齐；装填/上次武器保持原上下箭头语义与各类型摇杆、扳机映射，不再重画箭头或改动手柄。
- PS4 TYPE1/2/3：恢复原始图标列表，说明从原英文左锚点 x123 开始。
- 三张键盘操作图：面板背景 alpha67，边框、鼠标、键帽及连线保留原图。整行英文清除覆盖首字母边缘，防止出现孤立黑点。
- 16 张通用按键图例：保留原物理图标；文字首个非透明像素与英文完全同列，按钮后保留原有 2 列透明间距。Back 用原生字形的 -1 像素字距使两字在 22 像素内完成，不缩放字形或扩大纹理。
- 四张 Y Axis：使用“纵轴:”的窄冒号，文字框右缘 x187 小于难度值起点 x188；原英文文字及原冒号全部清除。

通用字形工具增加 `ink_align: left` 和 `letter_spacing`，不绑定特定语言。字距以原生逐字整数坐标绘制，保留字形笔画，不进行重采样。

`tools/audit_image_alignment.py` 检查原图例的首字形列、原始图标像素、文字框外残留、所有原生操作图的文字区域外像素一致性、方向箭头保护区，以及 PC/NX 十字键说明的 18 项水平中心检查。

本轮离线目标集为 32 图片、167 标签：原先完整汉化包在新门禁下 `FAIL issues=87`；修改配方重建后 `PASS issues=0`。测试加入左墨迹锚定、无重采样字距、面板被改成纯黑时审计必须失败、12 张操作图禁用整图差分与 Jump/冒号契约。
