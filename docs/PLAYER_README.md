# 《病房2》简体中文补丁：使用说明

适用于Steam 2026版《Dementium II》（AppID 5342930），不适用于2013年HD版。
当前补丁v1.1.4支持已验证build 26099941 / 26123896 / 26152271 / 26260428 / 26286386；旧v1.0的完整通关报告仅对应旧build，新版目前完成离线验证。

## 下载、安装与恢复

从[发布列表](https://github.com/jyh9521/Dementium-II-CN/releases)下载 `Dementium-II-CN-v1.1.4.exe`。
退出游戏，运行安装器，确认自动检测路径，或手动选择游戏目录中的 `rom.zar`，然后安装。
安装器运行无需Python或另装.NET；安装器不含游戏本体，不启动游戏，不修改存档。安装后从Steam正常启动游戏。
恢复原版使用安装器恢复功能； `cn-backup`保存本次安装的原版ROM/EXE与身份记录，安装期间请勿删除，完整恢复校验成功后自动清理。
可信旧版可直接升级，原版备份不会被旧汉化覆盖。详情见[安装与恢复](INSTALLATION_GUIDE.md)。

## 阅读与菜单

- 长文保留标题、分段与缩进，用上下键、鼠标滚轮或右摇杆滚动；持续推住摇杆可连续滚动。
- 短文与明信片保持独立排版，完整显示的页面不接管滚动。
- F1开关原生中文菜单，支持鼠标、滚轮、方向键；Enter/Z确认，Esc/X取消。
- 持续作弊选项可取消，一次性按钮只执行一次；原生无限弹药不会从零自动创造弹药。

## 字体与内容

正文/英文为Fusion Pixel12px，章节中文为ChillBitmap16px；“辘”“骶”补字已统一正文尺寸和基线。
不可辨原画微字、英文LOGO、公司名、按键标识、字母谜题与明确保留专名不作猜译。
显示差异及反馈入口见[已知问题](KNOWN_ISSUES.md)。
