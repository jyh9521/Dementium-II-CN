《病房2》Steam 2026版 简体中文汉化安装器 v1.1.2（内部版本1.1.2）

使用方法
1. 退出游戏，运行 Dementium-II-zh-CN-Setup.exe。
2. 自动检测Steam库，或点击“浏览”选择游戏根目录的rom.zar。
3. 可以直接点击“安装汉化”，不要求先检查文件。可选的“检查资源”用于查看是否能定位需修改内容。
4. 固定同时处理rom.zar和同目录Dementium II.exe，不会启动游戏。

补丁匹配方式
归档按成员名称与原始内容匹配，保留无关成员；改写目录/VFS尺寸并追加汉化内容。
本版同时开放F1原生作弊菜单并加入中文调试字体，需要对EXE执行字节级修改。
支持已验证的Steam build 26099941 / 26123896 / 26152271。其他版本须通过资源内容、修改位置、原字节、PE头及非资源节代码/数据特征检查；全部匹配才安装，失配则原文件保持不变。
已有旧汉化且安装记录、当前文件、原版备份均可验证时，可直接升级；使用已核对的原版备份生成新版。
待改资源变化、定位不唯一、备份损坏或程序身份不符时中止，不改动其他文件。

F1作弊菜单
按F1打开/关闭；鼠标操作，菜单开启时沿用原生角色输入屏蔽和鼠标捕获解除。
无限生命、无限弹药等复选框可以再次取消；菜单关闭后已启用的持续效果保留。
恢复生命、获得武器/物品、杀敌、跳关、重置成就等按钮执行一次操作，并非可撤销开关。
零弹药需先取得弹药或武器；标题画面也可打开菜单，但需要角色/关卡的原生操作仍只在游玩中可用。
本版修正按钮残留/间距、操作图透明背景、方向箭头与说明对齐、跳跃文字、纵轴冒号及两张死亡图色调关系。

备份与恢复
安装前自动备份到游戏根目录 cn-backup，保留 rom.zar 和 Dementium II.exe 原文件名。
resource-state.json记录这一份实际输入的备份及安装结果身份；归档哈希用于备份/恢复完整性，原生菜单EXE另有精确身份与代码字节守卫。
恢复时选择同一rom.zar，点击“恢复原版”，恢复的是该次安装前的文件；双文件恢复并校验成功后删除整个 cn-backup，设置和存档不变。
恢复失败时保留备份供重试；恢复成功后下次安装会重新备份。
兼容已知旧安装器的原版备份迁移；无记录/无匹配备份的已汉化文件不会伪造原版备份。

权限与空间
写入权限不足时确认以管理员身份重新打开安装器；取消不会自动提升。
首次安装约需1.2GiB额外空间用于备份及临时结果；系统临时目录还须可写，以解包内置原生运行时。
临时结果完整后才替换，双文件提交失败会回滚到提交前状态；文件被外部程序改变时中止。

平台与说明
Windows x64，目标Windows10 1809及以上 / Windows11；不是所有历史系统或macOS/Linux通用程序。
内置.NET 10.0.13/WPF和MaterialDesignThemes 5.3.2，无需另装.NET/Python/WebView2，不启动时联网下载运行依赖。
保持固定LOGO和图标、Material Design主题及动画；不改游戏原版英文LOGO与公司名。
游戏文本和图片维持确认版本，不包含完整游戏归档或原版EXE。
不写Steam注册配置，不修改设置/存档，不创建系统卸载项。此项目构建未代码签名。
历史版本完成26123896原版副本安装/恢复、幂等、未知特征失配零写入验证、原生机器码回放及989张PNG审计；保留26099941已验证稀疏配方。未启动游戏，不等同新版游戏内或通关验收。
第三方许可随ZIP分发并嵌入EXE。

文档与菜单输入修正
长文保留原标题、分行、空段与缩进，字号尽量保持；溢出长文支持上下键/滚轮滚动。明信片、谜题及其他界面单独保护。
F1打开后箭头定位到菜单中央，鼠标限制在游戏客户区；滚轮、方向键、Enter/Z与Esc/X操作菜单。F1关闭后恢复原鼠标捕获；窗口失焦解除限制。
离线CPU/资源/安装恢复验证不代替真实窗口验收，修复后应人工检查。当前版本为v1.1.2。

本轮修复后的复验
- F1打开菜单，点击复选项和一次性按钮；按住、松开、关闭后重开不应误触。
- 拾取前查看明信片应显示正文，收藏页仍可阅读；正文布局与字号不变。
- 查看物品后退回主菜单再开始新游戏；修复了阅读器误写下一关卡覆盖名称的问题。
本轮没有启动游戏或改动存档；以上真实游戏操作需实机复验。

后续输入修复复验
- 菜单中用鼠标按住约一秒再松开，复选框应改变；键盘操作仍保持。
- 阅读首篇长文并关闭，再连续按E交互；普通游戏按键不应残留为按下状态。
本轮分别修正最外层Win32首次点击捕获门禁和阅读器跨模式按键释放，不修改字体、排版或关卡资源。

手柄长文滚动：右摇杆上推/下推模拟滚轮，推住可连续滚动；轻微偏移不滚动，普通视角和原键鼠操作保持。


v1.1.2支持已验证的Steam build 26099941、26123896、26152271。其他版本仅在资源、修改位置和原生特征全部匹配时安装；任意不匹配则停止，原文件保持不变。新版增加“行走晃动”设置翻译。v1.1.2采用手动发布流程，旧v1.0不适用于26123896。
