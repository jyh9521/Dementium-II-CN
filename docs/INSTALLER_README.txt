《病房2》Steam 2026版 简体中文汉化安装器 1.1.0

使用方法
1. 退出游戏，运行 Dementium-II-zh-CN-Setup.exe。
2. 自动检测Steam库，或点击“浏览”选择游戏根目录的rom.zar。
3. 可以直接点击“安装汉化”，不要求先检查文件。可选的“检查资源”用于查看是否能定位需修改内容。
4. 固定同时处理rom.zar和同目录Dementium II.exe，不会启动游戏。

补丁匹配方式
归档按成员名称与原始内容匹配，保留无关成员；改写目录/VFS尺寸并追加汉化内容。
本版同时开放F1原生作弊菜单并加入中文调试字体，需要对EXE执行字节级修改。
程序部分精确支持已核对的Steam build26099941原版EXE；先验证完整哈希、尺寸及旧字节，不向未知程序套用代码修改。
已有旧汉化且安装记录、当前文件、原版备份均可验证时，可直接升级；使用已核对的原版备份生成新版。
待改资源变化、定位不唯一、备份损坏或程序身份不符时中止，不改动其他文件。

F1作弊菜单
按F1打开/关闭；鼠标操作，菜单开启时沿用原生角色输入屏蔽和鼠标捕获解除。
无限生命、无限弹药等复选框可以再次取消；菜单关闭后已启用的持续效果保留。
恢复生命、获得武器/物品、杀敌、跳关、重置成就等按钮执行一次操作，并非可撤销开关。
零弹药需先取得弹药或武器；标题画面也可打开菜单，但需要玩家/关卡的原生操作仍只在游玩中可用。
本版修正按钮残留/间距、操作图透明背景、方向箭头与说明对齐、跳跃文字、纵轴冒号及两张死亡图色调关系。

备份与恢复
安装前自动备份到游戏目录.dementium-locale，原件命名为original-完整SHA256.zar / .exe。
resource-state.json记录这一份实际输入的备份及安装结果身份；归档哈希用于备份/恢复完整性，原生菜单EXE另有精确身份与代码字节守卫。
恢复时选择同一rom.zar，点击“恢复原版”，恢复的是该次安装前的文件，保留备份、设置和存档。
游戏更新为新原版后，可生成新的独立备份，不覆盖旧备份。
兼容已知旧安装器的原版备份迁移；无记录/无匹配备份的已汉化文件不会伪造原版备份。

权限与空间
写入权限不足时确认以管理员身份重新打开安装器；取消不会自动提升。
首次安装约需1.2GiB额外空间用于备份及临时结果；系统临时目录还须可写，以解包内置原生运行时。
临时结果完整后才替换，双文件提交失败会回滚到提交前状态；文件被外部程序改变时中止。

平台与说明
Windows x64，目标Windows10 1809及以上 / Windows11；不是所有历史系统或macOS/Linux通用程序。
内置.NET 10.0.13/WPF和MaterialDesignThemes 5.3.2，无需另装.NET/Python/WebView2，不启动时联网下载运行依赖。
保持用户指定LOGO和图标、Material Design主题及动画；不改游戏原版英文LOGO与公司名。
游戏文本和图片维持确认版本，不包含完整游戏归档或原版EXE。
不写Steam注册配置，不修改设置/存档，不创建系统卸载项。此项目构建未代码签名。
当前完整包验证了26099941原版副本、安装/恢复、旧汉化升级失败回退、F1/生命/弹药的隔离原生机器码回放与988张PNG审计；未启动游戏，不等同游戏内或通关验收。
第三方许可随ZIP分发并嵌入EXE。
