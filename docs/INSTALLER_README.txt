《病房2》Steam 2026版 简体中文汉化安装器

使用方法
1. 退出游戏，运行 Dementium-II-zh-CN-Setup.exe。
2. 点击“浏览”，选择自己的 rom.zar（通常在Steam游戏安装目录中）。
3. 点击“验证文件”。仅支持Steam 2026 build 26091059指定原版，或本安装器已安装版本。
4. 验证通过后点击“安装汉化”，确认后等待完成。安装器不会启动游戏。

同目录存在Dementium II.exe时，默认同时处理其中的5个固定菜单词。
如果只想处理独立的rom.zar，可取消勾选“同时处理同目录EXE中的5个菜单词”。
没有同目录EXE时自动切为仅资源模式；此时程序中的5个菜单词仍保留原文。

恢复原版
重新运行安装器，选择同一rom.zar，验证后点击“恢复原版”。
原始文件保存在游戏目录的 .dementium-locale/original.zar 和 original.exe。
恢复完成后仍保留备份，不删除设置或存档。请保留该备份目录。

权限与空间
如果目标目录需要管理员权限，界面会提供“以管理员身份重新打开”。
首次安装约需1.2GiB额外空间用于原版备份和临时结果；磁盘不足时不会替换游戏文件。

安装器信息
适用于Windows 10/11 x64，使用系统.NET Framework 4.8，不要求安装Python或下载完整rom.zar。
EXE仅内嵌稀疏差分及本地界面；不会下载游戏、修改注册表、创建系统卸载项或自动启动游戏。
文件先核对大小和SHA-256，再生成临时结果；结果验证通过后才替换。重复安装/恢复不重复修改。
两个文件的提交发生异常时会尝试恢复提交前状态；中断后的原版/汉化混合状态可以继续安装或恢复。
未知版本、备份损坏或无可信备份的已修改文件不会直接覆盖。
这是未进行代码签名的项目构建，不是游戏发行商的官方安装程序。
