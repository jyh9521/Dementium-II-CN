《病房2》Steam 2026版 简体中文汉化安装器

使用方法
1. 退出游戏，运行 Dementium-II-zh-CN-Setup.exe。
2. 启动后会读取 Steam 注册位置、libraryfolders.vdf 和 AppID 5342930 的安装清单，查找各个 Steam 库。
3. 检测结果只填写路径，不修改游戏。找不到时点击“自动检测”重试，或“浏览”选择游戏根目录的 rom.zar。
4. 点击“验证文件”，通过后点击“安装汉化”并确认。
5. 固定同时处理 rom.zar 和同目录 Dementium II.exe，没有仅资源选项。
仅支持 Steam 2026 build 26091059 指定原版，或本安装器已安装版本；不会启动游戏。

恢复原版
选择同一 rom.zar，验证后点击“恢复原版”。
原始文件保存在游戏目录 .dementium-locale/original.zar 和 original.exe。
恢复后仍保留备份，不删除设置或存档。请保留备份目录。

权限与空间
写入权限不足时提供确认后以管理员身份重新打开安装器；取消不会自动提升。
首次安装约需1.2GiB额外空间用于备份和临时结果，另需系统临时目录可写用于内置运行时解包。

兼容与内容
此构建为 Windows x64 桌面程序，目标 Windows 10 1809及以上 / Windows 11；实际验证主机见验证记录。
内置 .NET 10.0.13 和 WPF 运行时，无需另装 .NET、Python、WebView2，不在启动时联网下载依赖。
不承诺所有历史 Windows、32位系统或 macOS/Linux 通用运行；系统版本、架构、写入权限和临时空间仍需满足要求。
采用 MaterialDesignThemes 5.3.2 的 Material Design 3 主题、按钮波纹/状态动画、界面入场和确认对话框过渡。
安装器中文LOGO和应用图标采用用户指定图片，仅用于安装器；游戏主界面英文LOGO与公司名不变。
文本和游戏图片差分维持已确认版本；不包含完整rom.zar或原版EXE。
文件先核对大小和SHA-256，再生成临时结果；通过校验后才替换。
双文件提交异常时回滚到提交前状态；中断后的原版/汉化混合状态可继续安装或恢复。
不会写入Steam注册配置、修改存档/设置、创建系统卸载项或自动启动游戏。
本构建未代码签名；安装与恢复的离线副本验证不等同完整通关验收。
完整第三方许可随ZIP提供，并嵌入EXE。
