# 截图问题修复（2026-10-21）

## 已验证的原因和修改

1. 安装中的 U+2026（省略号）有 glyph 元数据，但对应 PNG alpha 区域全空。截图中“看看仪表……拖拖地……挖”缺的是标点墨迹，不是这里的汉字。构建器现在检查实际墨迹，自动重建被使用的空白非空格字形；新增字形也拒绝空墨迹。正文/对话共享该字库，原始图集像素仍保留。
2. 译文手工软换行被按实际字宽二次折行，产生“西！”等短尾。18个长篇散文文档通过 locale 配置连接软换行、保留标题和空段落，再按228逻辑像素重排，尾段优先保留至少52像素。诗歌、谜题、表格/SUB物理记录和刻意错落的530不套用散文重排。原始逻辑译文不被构建函数改写；控制码/变量完整保留。
3. 四种输入设备的 YAXIS 提示仅保留现成图片前两字“纵轴”，清除后两字“反转”，保持Y键和其他像素。墨迹终点在x=181之前，给截图难度值起点约x=188留出空间。此几何门禁来自实机截图，不作为新实机验收。
4. OPTIONSNEW.TBL:0041/0042 从“轻微/强烈”改为“半透明/不透明”，明确显示透明度而非效果强度，不改变实际选项数值或功能。
5. 23条资源译文里的所有长破折号改成两侧带空格的 ` - `，包括署名和标题。字体预览与明信片署名识别配置同步更新；英文日期/专名中的连字符不改。

## 验证

基线回归复现：空白字形U+2026、2条短尾、23条含长破折号的译文、小地图语义不符、纵轴图片重叠区有墨迹。
修改后上述门禁全部通过，676条资源二次提取、控制码、差分、VFS索引/字体解码、41个图片和5个EXE标签验证通过；123项单元测试通过。
完整命令、输入、输出、哈希及隔离回滚见本地 `build/text-layout-fix/VERIFICATION.txt`。回滚脚本恢复原版英文到另一个目录，不覆盖修复版本。
本轮不启动游戏，不修改存档；两张实机截图证明修改前问题，修改后仍需在相同对话、长文及设置界面人工确认。

## 维护

字体是否有cmap项不代表字形可见，必须检查图集alpha。不要全局删除省略号或把中文正文替换为近形字来绕过空白字形。
后续文档可在locale的prose_layouts中配置软换行及短尾预算；不得按汉字或语言名称硬编码到通用构建器。
